# ReviewInsight-QA 电商评论洞察问答系统

一个基于 RAG（检索增强生成）的电商评论分析工具：读入用户评论，支持自然语言问答（带引用溯源）、评论维度统计和一键生成产品洞察报告。

## 功能

1. **评论问答**：用大白话提问（如"续航怎么样""大家吐槽最多的是什么"），系统检索语义最接近的评论，由大模型基于真实评论回答，每句标注引用编号，可溯源到原始评论
2. **维度统计**：按音质/续航/佩戴舒适度/连接稳定性/物流包装/客服售后/降噪/性价比 8 个维度，自动统计提及次数与好评差评数
3. **洞察报告**：一键生成结构化产品洞察报告（核心好评点 / 集中吐槽点+改进建议 / 购买建议）

## 技术栈

- Python（pandas / numpy / requests）
- RAG 架构：评论向量化 + 余弦相似度检索 + LLM 生成
- 硅基流动 API：BAAI/bge-m3（向量）、Qwen/Qwen2.5-7B-Instruct（对话）

## 运行环境

百度 AI Studio 云端 Notebook（免费），或任何 Python 3.8+ 环境（仅需 pandas、numpy、requests）。

## 使用方法

1. 在 notebook 第 1 格填入硅基流动 API 密钥
2. 从上往下逐格运行即可
